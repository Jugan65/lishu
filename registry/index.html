ARCHITECTURE REGISTRY

让新的结构
能够被看见。

Architecture Registry 用于记录生态中产生的新方法与新结构。 我们关注的是“解决了什么问题、怎么构造、观察到了什么”， 而不是要求作者公开全部生产源码。

Architecture Card

01 名称 / 作者 / 版本

用于建立明确的成果归属与历史记录。

02 解决的问题

这个结构试图解决什么问题，以及使用场景是什么。

03 基础依赖

使用了哪些公开组件、协议或已有结构。

04 核心结构

描述输入、状态、处理步骤和输出之间的关系。

05 核心流程

通过文字、流程图或简化示意说明主要运行路径。

06 新增部分

相对已有基础增加了哪些新的组织方式或机制。

07 实验观察

如何测试，以及观察到了哪些结果。

08 已知限制

目前尚未覆盖、尚未验证或可能不适用的场景。

09 源码状态

Open Source / Private / Commercial，由作者自行说明。

Submit Architecture

通过 GitHub Issue Form 提交新的 Architecture Card。 提交 Architecture Card 不代表转让代码或成果所有权。
